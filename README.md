# 加油站班次交接

- 行业：石油
- 技术栈：Vue 3、Vite、TypeScript
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 可重放班次账本

页面不再整份覆盖班次记录，而是把以下操作都追加为不可变本机流水：

- 开班
- 销售
- 退款
- 班次复核
- 待核冲突核账
- 关班

每笔流水包含收银机、本机流水号、录入时间、业务时间和确认时间。在线时立即确认；断网时先写入本机，重连或崩溃后重新打开页面时统一确认并重放。

合并规则：

- 同一销售或退款凭证的完全相同流水自动去重。
- 同凭证但现金、电子支付或升数不同的流水进入待核区，并列显示双方金额。
- 双方复核结论不一致也进入待核区。
- 核账结论本身也是流水；多台机核账结论不同会继续保留待核。
- 待确认和未核账流水暂不计入班次净额。
- 未复核、有未确认流水或有未核冲突的班次不能关班。

旧版 `localStorage` 数组（`dfwlfront-7-shift`）首次打开 V2 时自动升级，原始数组不会被覆盖。升级按旧记录中的开班、汇总销售、复核事件逐条写入检查点，中断后再次打开会跳过已完成事件并继续。

所有数据仍保存在浏览器 `localStorage`，事件键前缀为：

```text
dfwlfront-7-shift-ledger-v2:event:
```

后续接入服务端时，可把 `appendEvent`、`scanEvents`、`confirmPendingEvents` 替换为同步接口，页面仍通过 `replayLedger()` 读取物化后的班次视图。
